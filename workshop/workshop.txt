title=Multiplayer Time Controls
description=The single-player speed buttons, in multiplayer: pause, normal speed and the three fast-forward speeds (5, 20 and 40 times), in the same place under the clock and on the same keys you use in single player.
description=
description=The speed is one speed for the whole server. When somebody pauses or fast-forwards, it happens for everyone, and everyone sees who did it.
description=
description=[h2]What it does[/h2]
description=[list]
description=[*][b]Buttons[/b] at the top right, where single player has them. The speed that is on is red. A line under them says who changed the speed, or why it went back to normal.
description=[*][b]Your own speed keys[/b] work (Options, Key Bindings: Pause, Normal Speed, Fast Forward x1, x2, x3; F2 to F6 unless you changed them).
description=[*][b]Pause[/b] stops the world for everybody: the clock, zombies, hunger, actions and every player's character. The screen says who paused. Chat, the inventory and the menus keep working. Press pause again to go back to the speed it was at.
description=[*][b]Fast forward ends by itself[/b], for everyone, when a player presses a movement key, attacks or drives (as in single player), when zombies are after a player or close to one, and when a player dies.
description=[/list]
description=
description=[h2]What the server owner decides[/h2]
description=Three sandbox options on the page [b]Multiplayer Time Controls[/b]. The server checks them.
description=[list]
description=[*][b]Who can change the speed[/b]: Everyone (default) or Admins only.
description=[*][b]Pausing allowed[/b] (on).
description=[*][b]Fastest speed[/b]: none, x1 (5 times), x2 (20 times) or x3 (40 times, the default).
description=[/list]
description=A pause or a fast forward never outlives the people who could end it: the speed goes back to normal when the server is empty, or when the last admin leaves an "Admins only" server.
description=
description=[h2]Multiplayer[/h2]
description=The server and every player need the mod. Add the Workshop ID and the Mod ID below to the server's settings. It does nothing in single player, which has its own buttons.
description=
description=[h2]Good to know[/h2]
description=[list]
description=[*]Build 42.22 or newer. Tried on a dedicated server with one player; not yet with several players at once, on a server hosted from the game, with a controller, or with vehicles.
description=[*]Everybody moves faster in fast forward, as in single player. A dedicated server's speed anti-cheat would kick a character walking at 20 times speed, so the mod switches that one check (AntiCheatSpeed) off while the world runs fast and puts the server's own setting back five seconds after. Nothing is written to the server's .ini. To keep the check on at all times, set Fastest speed to "No fast forward".
description=[*]During a pause the mod holds the game's "Render UI offscreen" option off, so windows and chat keep drawing, and puts it back afterwards.
description=[*]Sleeping is unchanged.
description=[/list]
